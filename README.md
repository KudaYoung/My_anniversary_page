## 📸 功能亮点

### 1. 更多回忆 (Gallery)
支持**瀑布流布局**。每一张图片在加载高清原图前都会显示“正在加载中...”，比你的网速更有耐心。

### 2. 纪念时间轴 (Timeline)
一根挺拔的竖线，节点左右交错排开。手机端会自动变成单列模式，适配各种屏幕大小。

### 3. 高级灯箱 (Lightbox)
* **模糊背景**：背景自动提取当前照片并模糊放大，彻底消灭两侧黑边。
* **自动换行**：支持长篇大论的描述文字，哪怕你写了一篇长情书，它也装得下。
* **快捷导航**：支持键盘左右键切换，像翻阅纸质相册一样自然。

## 🚀 快速开始

1.  **克隆项目**：
    ```bash
    git clone https://github.com/KudaYoung/My_anniversary_page.git
    ```
2.  **替换照片**：
    打开 `js/gallery.js` 和 `script.js`，把你那些压箱底的好看照片 URL 填进去。
3.  **上线营业**：
    把这些文件丢到 GitHub Pages、Vercel 或者你自己的服务器上。
